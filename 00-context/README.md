# 00-context

Kim olduğumuz, müşterimizin kim olduğu, hangi dili kullandığımız.

- `customer-profile.md` — principals, dinamikler, karar mekanizması
- `our-positioning.md` — yasak/tercih kelimeler, ton örnekleri, ufuk isimleri
- `meeting-notes/` — her müşteri etkileşimi için bir dosya (`YYYY-MM-DD-<topic>.md`)
