# 03-proposal

Müşteriye gidecek doküman — mesajlama için **source of truth**.

- `outline-de.md` — bölüm iskeleti, Türkçe iç notlarla
- `draft-de.md` — tam Almanca taslak
- `assets/diagrams/` — süreç haritaları, timeline, konumlandırma matrisleri
- `assets/screenshots/` — mevcut sitenin sorun kanıtları

Versiyonlama: çalışma dokümanları işaretsiz, müşteri sürümleri `v1.0`, `v1.1` …
